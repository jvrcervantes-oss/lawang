Plantillas de contrato

Las plantillas con las que se hacen vuestros contratos y los tipos de contrato que existen. Cada cambio se guarda como borrador; solo pasa a usarse cuando un responsable lo activa. Una versión activa no se cambia: se hace otra, y cada contrato recuerda con qué versión se hizo.

Estas plantillas son vuestras. AxisWorks no las redacta ni las revisa, y no responde de su contenido. Una plantilla solo se activa cuando alguien con permiso revisa el texto y lo confirma. Las plantillas incluidas de serie no aparecen en esta lista.

Trayendo los tipos…

El prefijo es la serie de numeración de sus contratos (AL00001, AL00002…): se pone una vez y no se cambia, para no partir la serie. Un tipo no se borra: se desactiva y deja de ofrecerse para contratos nuevos.
